# Интеграция Kodik API

Документация для ИИ-агентов и разработчиков, реализующих интеграцию с Kodik API в этом проекте.

## С чего начать

1. Прочитай [`AGENTS.md`](AGENTS.md) — обязательные правила работы с интеграцией.
2. Открой описание нужного endpoint в [`methods/`](methods/).
3. Для параметров, используемых несколькими endpoint, проверь [`parameters/parameter-index.md`](parameters/parameter-index.md), затем [`parameters/common.md`](parameters/common.md).
4. Если описание endpoint уточняет общий параметр или задаёт особое поведение, приоритет имеет описание endpoint.
5. Не придумывай поля ответа, значения параметров, ограничения и поведение, которых нет в документации. При нехватке данных явно укажи неопределённость.

## Базовые сведения

- Базовый адрес API: `https://kodik-api.com`.
- API-токен обязателен для описанных методов; хранить его нужно в конфигурации/секретах проекта, а не в исходном коде.
- Подробности формата запросов, полей ответа, фильтров и ограничений смотри в файле соответствующего endpoint.
- Эта документация перенесена из предоставленных описаний Kodik. Она не является гарантией того, что поведение API не изменилось; при спорных моментах сверяйся с актуальным официальным описанием и реальными ответами API.


## Примеры запросов и ответов

Каждый файл в `methods/` содержит примеры HTTP-запроса и JSON-ответа. Токен в примерах заменён на `<KODIK_API_TOKEN>`: используйте секрет из конфигурации окружения. Примеры ответов могут быть сокращены, что отмечено рядом с ними.
